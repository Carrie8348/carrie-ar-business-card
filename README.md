# Carrie AR Business Card

An interactive WebAR business card that brings my creative portfolio to life.

Point your smartphone camera at the business card to watch an animated portfolio featuring selected work in **Design, Code & Film**.

Tap the AR experience to explore my full portfolio.

## Features

- Image-tracking WebAR experience
- Animated portfolio video
- Interactive portfolio link
- Optional audio playback
- Mobile-friendly interface

## Built With

- MindAR
- Three.js
- HTML, CSS & JavaScript
